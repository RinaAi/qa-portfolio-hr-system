# Test Plan - QA Compass

**Модуль:** «Моя информация»  
**Роль:** ESS  
**SRS:** v2.1  
**Тип:** Учебный / Портфолио

## 1. Цель

Проверить ключевые сценарии модуля «Моя информация» для роли ESS:
- отображение и редактирование доступных данных
- права доступа (read-only поля)
- работа с вложениями (лимит 1 MB)
- валидация и динамические поля

## 2. Область тестирования

**Входит:**
- Личные данные
- Контактные данные
- Вложения
- Smoke-проверка открытия модуля
- NFR-01 и NFR-02

**Не входит:**
- Остальные подразделы модуля
- Роль HR-администратора
- Другие модули системы
- Интеграции и нагрузочное тестирование

## 3. Подход

- Ручное тестирование
- Техники: эквивалентное разделение, граничные значения, негативное тестирование
- Приоритет: Smoke и High → Medium
- Тест-кейсы ведутся в Notion

## 4. Окружение

| Параметр     | Значение                         |
|--------------|----------------------------------|
| Система      | https://hr.qacompass.ru          |
| Роль         | ESS                              |
| Браузеры     | Chrome, Firefox, Edge            |
| Инструменты  | Chrome DevTools, Notion          |

## 5. Критерии входа

- SRS v2.1 доступна и содержит актуальные требования
- Тестовая среда доступна
- Пользователь с ролью ESS создан и имеет необходимые права
- Тестовые данные подготовлены
- Функциональность, заявленная в scope, доступна для тестирования

## 6. Критерии выхода

- Выполнены запланированные тест-кейсы в выбранном объёме
- Найденные дефекты зафиксированы
- Подготовлен Test Summary

## 7. Результаты

Фиксируются в Notion и отражаются в Test Summary.
