## 📌 Описание проекта

Данный репозиторий содержит комплексную тестовую документацию по модулю **«Моя информация» (My Info)** веб-системы [QA Compass](https://hr.qacompass.ru).

Тестирование проводится на основе официальной спецификации требований (**SRS v2.1**) и сфокусировано на:
- функциональности модуля для роли **ESS-пользователя**;
- проверке прав доступа (read-only поля);
- работе с файловыми вложениями (лимит 1 MB);
- динамических полях и валидации форм.

## 🚀 Выполненные работы

### 1. Анализ требований и RTM
- Проведён детальный анализ всех функциональных требований (`FR-MI`, `FR-ATT`, `FR-PD`, `FR-CD`, `FR-EC`, `FR-DP`, `FR-PP`, `FR-JB`, `FR-SL`, `FR-RP`, `FR-QL`, `FR-UN`) и нефункциональных (`NFR-01`–`NFR-04`).
- Составлена **Матрица трассировки требований** со 100% покрытием (**66/66** требований).

### 2. Проектирование тестов (Test Design)
- Разработаны позитивные и негативные сценарии.
- Применены техники тест-дизайна:
  - **Эквивалентное разделение**
  - **Анализ граничных значений** (размер файлов ≤ 1 MB, форматы `.jpg`, `.png`, `.gif`)
  - **Тестирование состояний и переходов** (динамическое поле «Другое» в иждивенцах)
- Составлены чек-листы для проверки прав доступа роли ESS (read-only поля: ФИО, зарплата, должность, рабочий email и др.).

### 3. Тестирование
- Валидация работы форм и REST API (проверка статус-кодов, ошибок валидации `400 Bad Request` через Chrome DevTools).
- Проверка отображения и поведения блока «Вложения» в соответствующих подразделах.
