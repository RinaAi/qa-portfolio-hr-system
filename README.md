## 📌 Описание проекта
Данный репозиторий содержит комплексную тестовую документацию и результаты тестирования модуля **«Моя информация» (My Info)** веб-системы [QA Compass](https://hr.qacompass.ru/dashboard/index). 

Тестирование проводилось на основе официальной спецификации требований (**SRS v2.1**), сфокусированной на валидации функциональности, ролевой модели доступа (ESS-пользователь) и работы с файловыми вложениями.

## 🚀 Выполненные работы

1. **Анализ требований и RTM:**
   * Проведён детальный анализ функциональных (`FR-MI`, `FR-ATT`, `FR-PD`, `FR-CD`, `FR-EC`, `FR-DP`, `FR-PP`, `FR-JB`, `FR-SL`, `FR-RP`, `FR-QL`, `FR-UN`) и нефункциональных (`NFR-01..03`) требований.
   * Составлена **Матрица трассировки требований (Requirement Traceability Matrix)** со 100% покрытием всех 12 подразделов модуля.

2. **Проектирование тестов (Test Design):**
   * Разработаны позитивные и негативные сценарии тестирования.
   * Применены техники тест-дизайна: *эквивалентное разделение*, *анализ граничных значений* (для файлов и фото до 1 MB, типов форматов `.jpg`, `.png`, `.gif`), *тестирование состояний и переходов* (динамические поля).
   * Составлены чеклисты для проверки прав доступа роли ESS (Read-Only поля: зарплата, должность, личные данные).

3. **Тестирование и DevTools:**
   * Проведена валидация работы форм и REST API (проверка статус-кодов ответов и ошибок валидации `400 Bad Request` в Chrome DevTools).
